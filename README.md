# TamilChat Online (தமிழ் சாட்)

> **Official Domain:** [https://tamilchat.online/](https://tamilchat.online/)

Tamil Nadu's #1 free anonymous **Tamil Chatting Website**, **Tamil Random Chatting & Calling**, and **Tamil Stranger Chat** platform. Connect with Tamil speakers across Tamil Nadu (Chennai, Coimbatore, Madurai, Trichy, Salem, Tirunelveli, Vellore) and global Tamils (Singapore, Malaysia, Sri Lanka, Gulf NRIs, USA, UK) with zero registration, zero phone numbers, and zero logins.

---

## 🌟 Key Features

- **Tamil Random Chatting & Calling:** 1-click random stranger matching for spontaneous text chats and WebRTC video calls.
- **Anonymous Voice & Video Calling:** Encrypted peer-to-peer WebRTC video and audio calling with zero coin fees or limits.
- **Tamil Nadu Public Lobbies & Chatrooms:** Active group lobbies for cinema, trends, regional banter, and friendship.
- **Tamil Quick Phrases:** 1-tap Tamil conversation starters (வணக்கம் நண்பா!, எப்படி இருக்கீங்க?, சாப்பிட்டாச்சா?, வேற மாதிரி!, etc.).
- **Authentic Kollywood & Tamil GIFs:** Curated Vadivelu, Rajinikanth, Thalapathy Vijay, Thala Ajith, Santhanam, and Kollywood moments.
- **Zero Registration & Anonymity:** Jump in instantly with any display nickname and optional Tamil Nadu district tag.
- **End-to-End P2P Privacy:** Private messages and calls stream directly between users without server retention.
- **Progressive Web App (PWA):** Works smoothly on Android, iPhone (iOS), tablet, and desktop browsers.

## 🚀 Development & Build

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production & generate all static SEO routes
npm run build

# Preview production build locally
npm run preview
```

## 🌐 Custom Domain & Deployment

- Custom domain: `tamilchat.online`
- Configured via `public/CNAME` for GitHub Pages automated deployment.
- Static SEO routes generated via `node generate-routes.js` during build step.
